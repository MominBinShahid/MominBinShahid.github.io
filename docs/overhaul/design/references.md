# Visual references

35 sites, every URL fetched and confirmed live 2026-09-17. Gathered after two
design rounds were rejected — the second because I had fed the agents the
existing two-column architecture, so all four rebuilt the current site with
better typography.

**The point of this list is the layout patterns at the bottom.** They are the
vocabulary for describing what to build instead.

---

## Start with these five

1. **lynnandtonic.com** — Lynn Fisher. Her self-portrait homepage *redraws into a
   different illustration at every breakpoint*. Resize the window. The fastest cure
   for two-column thinking: the layout **is** the content, and there is no chrome
   at all.
2. **wattenberger.com** — Amelia Wattenberger, GitHub Next. Essays where scrolling
   drives the visualisation; prose and interactive figures are one instrument. The
   strongest "blog and showcase are the same object" example.
3. **tonsky.me** — Niki Prokopov. Highlighter-yellow everything, custom hand-drawn
   cursor. Pop achieved by **one committed decision** on a plain single column —
   proof that pop is nerve, not widgets.
4. **basement.studio** — the ceiling for full-bleed sectioned scroll. Display type
   doing the layout work, no sidebar anywhere. Steal the sectioning, not the WebGL.
5. **stephango.com** — Steph Ango, Obsidian CEO. One typeface, his own Flexoki
   palette, a bare list of essays. **This is the answer to the empty-blog launch
   problem** — a near-empty writing site that reads as taste rather than absence.

## Layout patterns that are NOT sidebar-plus-content

The recurring shapes among the best sites in the set.

**Full-bleed stacked sections** — the page as a sequence of full-width acts, type
set huge. basement.studio · lusion.co · locomotive.ca · obys.agency ·
darkroom.engineering. The dominant studio shape.

**Single column with art-directed interruptions** — a prose column that
periodically breaks to full-bleed figures or photographs. craigmod.com ·
wattenberger.com · ciechanow.ski · nerdy.dev. Best fit for an engineer who writes.

**Index-as-homepage** — no hero, no nav drama; the front page is one dense,
beautifully set list of everything. stephango.com · rsms.me · oimo.io ·
davidrudnick.org · antfu.me. Scales from 3 items to 300.

**Canvas-first with text overlay** — content floats on a live rendering surface.
p5aholic.me · lusion.co · bruno-simon.com · chartogne-taillet.com.

**Garden / wiki mesh** — navigation by inline links, backlinks and hover popups
instead of menus. gwern.net · wiki.xxiivv.com · jzhao.xyz · tomcritchlow.com.

**Costume-change identity** — themes or versions as a feature. localghost.dev
reskins entirely (vaporwave, 2003 GeoCities, lofi, 1999); p5aholic has a
monospace mode; Lynn Fisher numbers her redesigns.

## For an empty blog at launch

- **stephango.com** — a bare list plus topic tags reads as taste, not emptiness
- **robinrendle.com** — per-post art direction: three posts read as three *pieces*
- **antfu.me** — blog-as-homepage, the generative header carries the visual load
  while posts accumulate
- **100r.co** — a dated log with one illustration per entry; cadence makes short
  entries feel like a body of work
- **klim.co.nz** — publishes rarely, each essay definitive. Frames infrequency as
  depth
